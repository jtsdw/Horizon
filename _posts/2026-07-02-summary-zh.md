## [首个能生长分裂的合成细胞诞生](https://www.quantamagazine.org/for-the-first-time-a-cell-built-from-scratch-grows-and-divides-20260701/) ⭐️ 9.0/10

由明尼苏达大学合成生物学家 Kate Adamala 领导的研究团队创造了 SpudCell，这是首个完全由非生命化学组分构建并能生长、复制基因组和分裂的合成细胞。 这一突破标志着合成生物学的重要里程碑，首次展示了完整的合成细胞周期，可能彻底改变生物工程学以及我们对生命基本过程的理解。 SpudCell 缺乏细胞骨架，而是利用液滴融合与分裂的不同机制进行分裂。该工作已在线发布但尚未经过同行评审，且发表过程存在一些争议。

hackernews · defrost · 7月1日 14:20 · [社区讨论](https://news.ycombinator.com/item?id=48747304)

**背景**: 合成生物学旨在从头构建人工细胞，以理解生命并创造有用的生物技术。以往的合成细胞可以生长和复制 DNA，但无法分裂——这一复杂过程通常需要细胞骨架。Adamala 团队通过设计一种无需细胞骨架即可分裂的细胞绕过了这一难题。

## [索尼将于 2028 年停止 PlayStation 实体游戏光盘生产](https://blog.playstation.com/2026/07/01/physical-disc-production-ending-in-january-2028-for-new-games-releasing-on-playstation-consoles/) ⭐️ 8.0/10

## [ROSA：面向机器人工厂的共享 GPU 服务系统](https://arxiv.org/abs/2607.01088v1) ⭐️ 8.0/10

研究人员提出了 ROSA，这是一个面向机器人工厂的机器人基础模型服务系统，采用共享 GPU 池、多模型流水线和工厂目标驱动的调度策略，以提升推理性能和资源利用率。 ROSA 解决了现有单机器人、单模型服务系统的局限性，有望在工厂中实现更高效、可扩展的通用机器人部署，将生产力提升高达 12.06 倍。 ROSA 基于 Ray Serve 实现分布式编排，使用 vLLM、PyTorch 和 JAX 作为模型服务后端。它支持多模型流水线、每任务性能要求和故障处理。

rss · arXiv LLM Inference · 7月1日 15:45

**背景**: 机器人基础模型（RFM）是大型预训练模型，使通用机器人能够执行多种任务。现有的 RFM 服务系统通常假设单机器人配备专用 GPU，导致 GPU 利用率低且可扩展性有限。ROSA 提出了一种共享 GPU 池方法，允许多个机器人通过网络访问服务器级 GPU，从而提升性能和资源效率。

## [AGI Maze：评估 LLM 世界建模能力的新基准](https://arxiv.org/abs/2607.00627v1) ⭐️ 8.0/10

研究人员推出了 AGI Maze，这是一个轻量级基准框架，用于评估 LLM 在部分可观测、有状态环境中学习和使用世界状态表示的能力。初步测试表明，普通 LLM 无法在内部表示迷宫，即使使用消息历史作为工作记忆，也无法在人类足够用的步数预算内可靠地解决小型迷宫。 该基准填补了评估 LLM 持久状态表示能力的关键空白，这是实现 AGI 所需的世界建模的关键方面。当前 LLM 的失败凸显了它们在处理部分可观测、有状态任务方面的重大局限，推动该领域向更好的记忆和推理架构发展。 AGI Maze 提供了一系列基于网格的迷宫任务，具有简洁的 API 和多种难度级别，要求智能体学习和使用世界状态表示，而非推断局部规则。基线智能体使用消息历史作为工作记忆来构建观察描述，但仍然无法可靠地解决即使是小型迷宫。

rss · arXiv LLM Inference · 7月1日 08:43

**背景**: 大型语言模型（LLM）是强大的模式补全系统，能从静态上下文中预测下一个 token，但无法可靠地生成外部世界的持久、可操作表示。在部分可观测环境中，智能体无法看到完整状态，必须维护关于隐藏状态的记忆和结构化假设。AGI Maze 旨在无需高维感官输入的情况下测试这一能力，使用简单的网格迷宫。

## [BaseRT：苹果芯片上的原生 Metal 大模型推理](https://arxiv.org/abs/2607.00501v1) ⭐️ 8.0/10

BaseRT 是一个基于原生 Metal 的 LLM 推理运行时，在苹果芯片上解码吞吐量比 llama.cpp 最高提升 1.56 倍，比 MLX 最高提升 1.35 倍。 这表明苹果芯片是一个比以往报告更强大的推理平台，直接有利于边缘推理场景——隐私、延迟和成本正推动设备端部署。 BaseRT 支持 Qwen3、Llama 3.2 和 Gemma 4 等模型家族，在全部苹果 M 系列设备上提供八种量化格式（Q2 到 FP16），在混合专家模型的预填充阶段优势更大。

rss · arXiv LLM Inference · 7月1日 06:37

**背景**: 现有的 LLM 运行时（如 llama.cpp 和 MLX）基于并非为 Metal 执行模型或苹果芯片统一内存拓扑设计的抽象层构建。BaseRT 通过原生构建在 Metal 之上，并采用芯片特定的内核融合和统一内存感知优化，恢复了基于框架的方法所损失的性能。

## [ELDR：面向 MoE 服务的专家局部性感知路由](https://arxiv.org/abs/2607.00466v1) ⭐️ 8.0/10

ELDR 提出了一种针对预填充-解码（PD）分离的混合专家（MoE）服务的专家局部性感知解码路由方法，已在 vLLM 中实现并在多达 40 个 GPU 上评估，相比负载均衡基线将中位 TPOT 降低了 5.9%-13.9%。 这项工作通过考虑专家局部性而不仅仅是负载均衡，解决了 PD 分离 MoE 服务中的一个关键空白，在不改变模型输出的情况下显著降低了延迟。它直接惠及使用 MoE 架构的大规模 LLM 推理系统。 ELDR 从预填充激活中构建专家签名以预测未来的专家使用情况，使用平衡 K-means 离线划分签名空间，并在线应用局部性带路由将请求分配给负载最轻的匹配工作节点。与 KV 缓存共同索引的签名缓存确保了前缀缓存下签名的准确性。

rss · arXiv LLM Inference · 7月1日 05:34

**背景**: 在 PD 分离的 LLM 服务中，预填充和解码阶段被分配到不同的工作节点上。对于 MoE 模型，每个解码步骤需要加载批次激活的所有不同专家的权重，因此负载相同的工作节点可能具有不同的延迟。现有路由器仅平衡负载，忽略了专家局部性。ELDR 利用了这样一个观察：对于给定请求，专家激活在解码步骤中是一致的。

## [利用排斥笼通过避碰机制控制被入侵无人机](https://arxiv.org/abs/2607.01230v1) ⭐️ 8.0/10

研究人员提出一种分布式围堵框架，利用被入侵无人机仍活跃的避碰模块，通过防御者形成的排斥笼来引导其运动。 该方法通过重用现有安全层作为驱动通道来增强无人机蜂群安全性，无需检测或隔离被入侵个体。 交互被建模为在线 Stackelberg 博弈，防御者为领导者，对手做出反应；该框架相对于集中式基准实现了次线性动态遗憾。

rss · arXiv Agent Infra · 7月1日 17:59
